# Insomnia

## Workflow

Chaque nouvelle feature suit ces étapes :

1. **Créer une branche Git** au nom de la feature, à partir de `main` à jour (ex. `base-player-movement`).
2. **Basculer sur la branche.**
3. **Implémenter la feature** et noter les changements dans `CHANGELOG.md`.
4. **Pousser sur une branche GitHub** du même nom que la branche Git.
5. **Créer la Pull Request** vers `main`.
6. **Confirmer manuellement la PR** (merge fait à la main sur GitHub).

> Les noms de branches Git ne peuvent pas contenir d'espaces : on utilise des tirets (`ma-feature`).
